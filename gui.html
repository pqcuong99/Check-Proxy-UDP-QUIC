UDP OK = proxy nhận lệnh UDP ASSOCIATE và gói UDP thật (DNS) đi qua relay có trả lời  ·  UDP FAIL = nhận lệnh nhưng relay không chuyển gói (UDP "giả")  ·  UDP NO = không hỗ trợ (từ chối lệnh / HTTP CONNECT / SOCKS4)  ·  QUIC OK = server HTTP/3 trả lời gói QUIC v1 gửi qua proxy (ServerHello / Retry / Version Negotiation)
